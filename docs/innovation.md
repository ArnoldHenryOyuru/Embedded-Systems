# Innovation features (decide as a group)

Ideas to pick from:
- Tailgating detection: two entries with one valid scan
- Anti-passback: block a second entry for someone already inside
- After-hours alarm and repeated-invalid-scan alerts
- Energy report: time lights were on in empty rooms
- Signed/encrypted inter-terminal messages (ESP-NOW encryption or HMAC)
- Hashed PINs for schedule changes, with lockout after failed attempts
- Emergency evacuation: list everyone still inside
